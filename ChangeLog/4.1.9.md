# Version 4.1.9

## New Features

### Microsoft Graph: send complete MIME messages

`msgraph sendmail --mimebase64 <file.eml>` sends a complete RFC 5322 message
through Graph's MIME `sendMail` request format. The file is sent as-is after
base64 encoding; it is not parsed or template-rendered. The MIME file must
contain the message's recipients and content, and conflicting recipient,
content, attachment, header, priority, message-ID, and template options are
rejected. Microsoft Graph remains in control of the sending mailbox and may
replace or normalize sender details.
