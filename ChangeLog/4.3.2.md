# Version 4.3.2

## New Features

### sendmail: random RFC as the body

`--body-source rfc` (env `<PROTOCOL>BODYSOURCE=rfc`, config key
`body-source: rfc`) fills a `sendmail` message without any body (smtp, jmap,
ews, msgraph, gmail) with a random RFC from the IETF's archive at
rfc-editor.org.

- The full text is sent as plain text and as preformatted HTML, with a source
  link and a copyright (BCP 78) note. Text over 1 MiB is cut.
- When no subject is given, the subject is `RFC <number>: <title>`. RFCs
  already named in the action's default result logs are skipped.
- `--body-categories` applies to `wikipedia` only.
- If the fetch fails, a warning is logged and the static body is sent.

### sendmail: random poem as the body

`--body-source poetry` fills such a message with a random public domain poem
from PoetryDB (poetrydb.org), credited as its CC BY 4.0 data license asks.

- When no subject is given, the subject is `Poem: <title> by <author>`. Poems
  already named in the action's default result logs are skipped.
- If the fetch fails, a warning is logged and the static body is sent.
